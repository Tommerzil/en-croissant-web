# chess-server

Headless HTTP build of En Croissant. Run with:

    CHESS_DATA_DIR=/path/to/data CHESS_WEB_DIR=/path/to/dist cargo run --release

Env: CHESS_DATA_DIR (required), CHESS_BIND (0.0.0.0:8090), CHESS_WEB_DIR (./dist), CHESS_SOUND_DIR (../sound).

Routes: POST /api/cmd/<command> (generated by gen_routes.py), GET /ws/events, /api/fs/*,
/api/kv, /api/proxy, /api/health, /resources/sound/*, static SPA fallback.

## Regenerating routes / running tests

Regenerate routes after upstream adds or changes a command:

    python3 gen_routes.py && cargo check

Tests and lints:

    cargo test                        # server integration + unit tests
    cargo clippy -- -D warnings       # server crate only
    python3 -m unittest test_gen_routes   # route generator tests

`src/routes_gen.rs` is generated and committed; after running `gen_routes.py`
`git diff` should be empty unless an upstream command actually changed.
